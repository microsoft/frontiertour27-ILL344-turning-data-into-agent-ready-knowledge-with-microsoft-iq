# Summary

You gave agents Caldova context with Microsoft IQ:

- Web IQ search over MCP that grounds answers in current web content, with citable passages, images, and videos.
- Fabric IQ queries over MCP to a Fabric ontology for product, substance, and manufacturer relationships, and to a Fabric data agent for supplier performance trends.
- Work IQ tools over MCP that ask about, retrieve, read, and act on your Microsoft 365 email and calendar as the signed-in user.
- A Foundry IQ knowledge base with agentic retrieval over Caldova's purchasing policy and indexed supplier and sourcing documents.
- MCP servers for each IQ in the GitHub Copilot app.
